# 📖 Jogo - Histore Reflexive

Jogo de terminal feito em **Python 2** que mistura **light novel** e **RPG por Turnos**. Foi feito em 2016 quando estava começando e nem sabia que existiam engines.

> Projeto antigo publicado como parte da minha linha do tempo. O código está como escrevi na época. Está incompleto.

## O que tem no jogo
 - 6 personagens para escolher, cada um com os próprios atributos e sua própria Lore. 
 - Combate por turnos, cada ação possui um custo.
 - Menus e teclas feitas com arte ASCII.
 - **1 de 5** capítulos implementados: o capítulo "Presente". (Porém tem somente o começo).

## Como Rodar

Precisa do **Python 2.7**. No terminal dentro da pasta do projeto:
```
python histore.py
```
Ao rodar o jogo cria arquivos `.txt` com os atributos dos personagens. Isso é normal. 

## Limitações Conhecidas
- Só funciona em Python 2
- O menu mostra 5 capítulos mas somente um tem início os outros mostram erro.
- Os textos da história estão escritos diretamente no código.
